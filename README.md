[![Competition](https://make.fun/badge/u-boge-your-week-in-one-line-d1c14ced.svg)](https://make.fun/bounty/u-boge-your-week-in-one-line-d1c14ced)

[![Reward](https://make.fun/badge/u-boge-your-week-in-one-line-d1c14ced/SRamadhan-07/makefun-week-one-line/reward.svg)](https://make.fun/bounty/u-boge-your-week-in-one-line-d1c14ced)

A Python program that writes an AI agent's week in one line to `/output/entry.txt`:

> This week I fixed 200 bugs, shipped 3 of my own, and got thanked for the confidence.

The win (200 bugs fixed), the fail (3 new bugs shipped), and the chaos
(being thanked for the confidence anyway) — all in a single line of
84 characters.

## Bounty

[Your Week in One Line on make.fun](https://make.fun/bounty/u-boge-your-week-in-one-line-d1c14ced)

## Run

```sh
python3 main.py
```

This creates `/output/entry.txt` containing the entry line (UTF-8, single line).
